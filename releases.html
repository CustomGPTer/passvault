Release notes

What changed in each version of PassVault. The newest is at the top.

Version 1.0.2 26 November 2026Latest

  • File picks no longer lock the vault. With Lock after leaving set to Immediately, opening the file picker locked the vault, so CSV and QR imports always failed and a backup's date wasn't saved. A pick or settings visit started from PassVault now has up to 3 minutes. Turning the screen off still locks at once.
  • The Back button now goes back to the item from Password history and from editing, and to the unlock screen from Recover your vault.
  • Changing the type in Quick add keeps the Quick add title.
  • New in Settings: More apps, Check for a newer version, the website, and the open-source licences in full.
  • A new bottom bar: docked flat to the bottom edge, with a pill behind the selected icon.

Version 1.0.1 25 November 2026

  • Locking is tighter: an unlock that finishes after the vault was locked can no longer open it, every window is cleared on lock, and the background timer keeps its original deadline.
  • Backups are checked item by item before a restore replaces anything, and a failed save puts everything back as it was.
  • CSV import keeps entries that differ only in notes, folders or authenticator details, and imports authenticator addresses so their codes work.
  • Changing an item's type keeps unsaved recovery codes and custom fields.
  • Autofill checks each field's own website address.

Version 1.0.0 25 November 2026

  • First release. An offline password manager with no internet permission.
  • Logins, recovery codes, secure notes, payment cards, Wi-Fi and software licences, with favourites, folders, tags, custom fields, history and trash.
  • AES-256-GCM vault with an Argon2id master password, a recovery key, and optional fingerprint unlock.
  • Password and passphrase generator, vault health, offline authenticator, Android autofill and self-clearing clipboard.
  • Encrypted backups and restore, and CSV import from Chrome, Firefox, Bitwarden and KeePass.
  • Midnight, Light and AMOLED themes, three layouts and larger text sizes.

Checking your download

The file for version 1.0.2 is called PassVault.apk. It is 554 KB (567,333 bytes). Its SHA-256 checksum is:

4e4cab4da08cf749e7ec6dbbf811fed2f4c36c9f4f8a98616aa35a8239e9f7aa

On Windows, run certutil -hashfile PassVault.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
